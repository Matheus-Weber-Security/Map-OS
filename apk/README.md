# Aplicativo Mobile Map-OS / Nexus Ticket (Flutter)

Este diretório contém os instaladores APK oficiais do aplicativo mobile para Android do **Map-OS** (versão oficial `v2.0.2` do repositório [`map-os/map-os-app-flutter`](https://github.com/map-os/map-os-app-flutter)).

---

## Qual arquivo instalar no celular?

1. **`app-arm64-v8a-release.apk` (Recomendado):**
   * Compatível com **99% dos celulares Android modernos** (processadores de 64 bits: Samsung Galaxy, Xiaomi, Motorola, Realme, etc.).
2. **`app-armeabi-v7a-release.apk`:**
   * Destinado a smartphones Android mais antigos com processador de 32 bits.

---

## Como conectar o aplicativo ao sistema:

1. **Instale o APK:** Transfira o arquivo para o seu celular Android e instale (permita a instalação de fontes desconhecidas se solicitado).
2. **Ative a API no Nexus Ticket:**
   * Acesse o painel web em `Configurações > API`.
   * Ative a opção **API ligada** e clique em **Salvar**.
3. **No aplicativo:**
   * Abra o aplicativo no celular.
   * Na tela inicial/configurações do app, informe a URL do seu sistema (exemplo: `https://seu-dominio.com.br` ou o IP/porta caso em rede local).
   * Faça login com o seu e-mail e senha de usuário cadastrado no sistema.
